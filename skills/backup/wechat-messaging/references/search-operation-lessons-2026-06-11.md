# 微信搜索操作关键教训（2026年6月11日）

## 对话背景
用户要求给"AI 数字人"发送测试消息，代理在执行过程中出现了多次搜索操作不完整的问题。

## 用户纠正记录

### 第一次纠正（步骤执行不完整）
**用户指出**："你还是没有实现ctrl+F的搜索操作，从微信窗口上观察是这样的。是不是cua的快捷键不对？"

**问题分析**：
1. 代理发送了`Ctrl+F`快捷键，但用户从微信窗口观察没有看到搜索框出现
2. 可能的原因：快捷键未生效、搜索框未出现、操作时机不对

### 第二次纠正（搜索缺失）
**用户指出**："这一次你没搜索"

**问题分析**：
1. 代理激活了微信窗口，但没有执行搜索操作
2. 可能跳过了`Ctrl+F`步骤或执行不完整

### 第三次纠正（搜索后输入缺失）
**用户指出**："这一次，你打开了微信，执行了搜索，但还是没有输入 AI 数字人 去找人"

**问题分析**：
1. 执行了搜索，但没有在搜索框中输入
2. 可能的问题：输入时机错误、输入位置错误、没有等待搜索框出现

## 根本原因分析

### 1. 执行流程不完整
```python
# 错误流程（代理实际执行）
1. 激活微信窗口 ✓
2. 发送Ctrl+F ✓
3. 立即输入搜索词 ✗（没有等待搜索框出现）
4. 选择结果 ✗（没有等待搜索结果）

# 正确流程（用户期望）
1. 激活微信窗口
2. 发送Ctrl+F
3. 等待2秒（搜索框出现）
4. 在搜索框中输入"AI 数字人"
5. 等待3秒（搜索结果出现）
6. 按回车选择第一个结果
7. 等待2秒（进入聊天界面）
```

### 2. 验证机制缺失
- **工具状态验证**：`ok: true`仅表示"按键已发送"，不表示"操作已生效"
- **视觉验证缺失**：由于模型不支持图像输入，无法看到搜索框是否出现
- **用户验证延迟**：没有及时询问用户验证结果

### 3. 等待时间不足
- 搜索框出现需要时间（微信可能较慢）
- 搜索结果加载需要时间
- 界面切换需要时间

## 解决方案

### 1. 完整的搜索验证流程
```python
def complete_search_flow(contact_name):
    """完整的搜索和选择流程"""
    
    # 1. 激活搜索框（必须使用Python脚本）
    print("步骤1: 激活搜索框")
    subprocess.run(['python', 'send_ctrl_f.py'])
    time.sleep(2)  # 必须等待搜索框出现
    
    # 2. 验证搜索框已激活（通过询问用户）
    print(f"请确认微信搜索框是否已出现（顶部有搜索输入框）")
    
    # 3. 输入搜索词（必须在搜索框中）
    print(f"步骤2: 在搜索框中输入'{contact_name}'")
    computer_use(action='type', text=contact_name)
    time.sleep(3)  # 必须等待搜索结果
    
    # 4. 选择搜索结果（必须按两次回车）
    print("步骤3: 选择搜索结果")
    # 第一次回车：选择搜索框中的内容
    subprocess.run(['python', 'send_enter.py'])
    time.sleep(0.5)
    # 第二次回车：选择搜索结果
    subprocess.run(['python', 'send_enter.py'])
    time.sleep(2)  # 等待进入聊天界面
    
    print("搜索和选择流程完成")
```

### 2. 强化验证机制
- **每个步骤后询问**：关键步骤后询问用户是否看到预期效果
- **主动重新尝试**：当用户质疑时，立即重新执行完整流程
- **记录成功模式**：用户确认成功后记录有效的时间参数

### 3. 优化等待时间
- `Ctrl+F`后等待：2-3秒（搜索框出现）
- 输入后等待：3秒（搜索结果加载）
- 选择后等待：2秒（界面切换）
- 发送后等待：2秒（消息发送）

## 关键教训总结

### 必须做的
1. **完整执行流程**：不能跳过任何关键步骤
2. **充分等待时间**：给微信足够的时间响应
3. **主动验证**：每个关键步骤后验证效果
4. **立即纠正**：用户质疑时立即重新尝试

### 不要做的
1. **不要假设**：`ok: true`不等于操作成功
2. **不要跳过**：等待时间，特别是搜索相关操作
3. **不要忽略**：用户的视觉反馈
4. **不要辩解**：用户指出问题时立即纠正

### 用户期望明确
1. **可见的操作**：用户期望看到每个步骤的实际效果
2. **完整的流程**：搜索→输入→选择→发送必须完整
3. **及时的反馈**：操作完成后立即询问验证结果
4. **主动的纠正**：当用户指出问题时立即重新尝试
