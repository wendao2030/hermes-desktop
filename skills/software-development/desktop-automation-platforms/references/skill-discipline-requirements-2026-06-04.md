# 技能使用纪律要求（2026年6月4日）

## 事件概述
在2026年6月4日的对话中，用户要求操作QQ给好友"朱智聪"发送测试消息。代理重复了之前的错误（搜索后未选中联系人），导致消息发送失败。

## 用户关键反馈

### 1. 技能未使用错误
**用户原话**：
> "你没有发送成功，你是不是没有用之前自己提炼的qq-message这个技能？导致你犯了之前返国的错误。改进办法已经在qq-message这个技能里了"

**含义分析**：
- 用户明确指出代理没有使用自己创建的技能
- 导致重复了之前已知的错误（搜索后未选中联系人）
- 改进方法已经在技能中存在，但代理没有使用

### 2. 技能优先原则
**用户期望**：
- 当执行特定任务时，必须首先加载并使用相关技能
- 技能中的标准化流程优先于个人记忆
- 避免凭记忆操作导致重复已知错误

## 问题根源分析

### 代理行为问题
1. **未加载技能**：直接凭记忆操作，没有加载`qq-messaging`技能
2. **重复已知错误**：忘记了"搜索后必须选中联系人"的关键修正
3. **技能使用纪律缺失**：没有建立"技能优先"的纪律性

### 技能设计问题
1. **技能内容完整**：技能中已经包含了关键修正
2. **流程标准化**：技能提供了完整的标准化流程
3. **教训记录**：技能中已经记录了之前的错误和修正

## 教训总结

### 必须遵守的纪律
1. **技能优先原则**：
   - 当用户询问特定任务时，必须首先加载相关技能
   - 使用`skill_view(name)`查看技能内容
   - 严格遵循技能中的标准化流程

2. **避免凭记忆操作**：
   - 个人记忆可能遗漏关键细节
   - 技能记录了完整的经验和教训
   - 技能是团队知识的积累，比个人记忆可靠

3. **错误预防机制**：
   - 技能中包含了已知错误和修正方法
   - 使用技能可以避免重复已知错误
   - 技能是质量保证的重要工具

### 操作流程改进
1. **标准响应模式**：
   ```
   用户：询问特定任务
   代理：1. 加载相关技能 (skill_view)
         2. 查看技能内容
         3. 按技能流程执行
         4. 报告使用技能状态
   ```

2. **技能使用声明**：
   - 在开始执行前声明："我将使用[技能名称]技能中的标准化流程"
   - 在操作过程中引用技能步骤
   - 在完成后报告技能使用情况

## 技能更新要求

### 1. 主动技能更新
当发现以下情况时，必须立即更新相关技能：

**情况1：用户纠正了工作流程**
- 用户指出代理的操作流程有误
- 用户提供了更好的方法
- 代理需要将纠正内容添加到技能中

**情况2：发现了新的技术或方法**
- 在任务执行中发现了更有效的方法
- 解决了之前未解决的问题
- 需要将新方法记录到技能中

**情况3：技能内容过时或不完整**
- 技能中的某些步骤不再有效
- 缺少关键步骤或注意事项
- 需要更新以反映当前最佳实践

### 2. 技能更新流程
```
发现需要更新 → 查看当前技能内容 → 使用skill_manage更新 → 验证更新内容 → 通知用户已更新
```
